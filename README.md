# Saya AI Agent

واجهة محادثة ثنائية اللغة (العربية/English) تعمل على React + Vite وتستخدم مفتاح Google AI Studio من المتصفح مباشرة.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## الاستخدام

1. افتح التطبيق.
2. ادخل إلى **الإعدادات**.
3. أضف مفتاح Google AI Studio API.
4. اختر النموذج واللغة ثم ابدأ المحادثة.

> المفتاح يُخزن في متصفحك فقط، ويرسل إلى Google عند توليد الإجابات.
