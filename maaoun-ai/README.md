# معون AI — ai.maaoun.com

مساعد ذكاء اصطناعي عربي مستقل عن متجر معون، مبني على Cloudflare Workers + Static Assets، ولا يحتاج قاعدة بيانات أو اشتراك استضافة مدفوع لتشغيل واجهته ضمن حدود Cloudflare المجانية.

## المميزات

- عدة مفاتيح API وتبديل فوري بينها يدويًا (Gemini / OpenAI / Groq / DeepSeek / Claude / OpenRouter).
- جلب النماذج المتوفرة من مزود المفتاح، ودعم اسم نموذج يدوي.
- ردود متدفقة، محادثات متعددة، بحث، حذف، تصدير JSON.
- رفع صورتين (PNG/JPG/WebP)، وملفات نصية/برمجية صغيرة؛ يعتمد فهم الصور على دعم النموذج المحدد.
- إملاء صوتي عندما يدعم المتصفح واجهة SpeechRecognition.
- واجهة عربية RTL للجوال والكمبيوتر، دون CDN خارجي.
- جلسة فقط لحفظ المفاتيح افتراضيًا، مع خيار حفظها محليًا على مسؤولية المستخدم.

## التشغيل المحلي

يتطلب Node.js وnpm. من مجلد المشروع:

```bash
cd maaoun-ai
npx wrangler dev
```

افتح العنوان المحلي المعروض من Wrangler. لا تفتح public/index.html مباشرة من نظام الملفات: يجب أن تعمل واجهات /api عبر Worker.

## نشر الموقع إلى Cloudflare

1. تأكد أن نطاق maaoun.com مُدار عبر حساب Cloudflare الذي ستنشر إليه، أو اتبع خيار ربط النطاق الفرعي حسب مزود DNS.
2. ثبت Wrangler محليًا أو فعّل GitHub Action المرفق.
3. للحصول على رموز النشر، أنشئ **Cloudflare API Token** محدود الصلاحية بنشر Workers، واحصل على **Cloudflare Account ID**. لا ترسل المفتاح أو الرمز في المحادثة ولا تضعه في ملفات المستودع.
4. من GitHub -> Settings -> Secrets and variables -> Actions، أضف `CLOUDFLARE_API_TOKEN` و `CLOUDFLARE_ACCOUNT_ID`.
5. شغّل GitHub Actions -> Deploy Maaoun AI -> Run workflow (بعد دمج الفرع).
6. داخل Cloudflare -> Workers & Pages -> Workers -> `maaoun-ai` -> Settings -> Domains & Routes -> Add -> Custom Domain -> `ai.maaoun.com`. قد تحتاج إلى تعديل DNS لو كان نطاقك في حساب آخر. تحقق أن HTTPS فعال.

يمكن النشر يدويًا:
```bash
cd maaoun-ai
npx wrangler@4 deploy
```

يُنشر Worker في عنوان workers.dev أولًا؛ **ربط ai.maaoun.com ليس تلقائيًا** حتى تضيف النطاق الفرعي من لوحة Cloudflare.

## الأمان والحدود

- مفاتيح المستخدم لا تُكتب في الشفرة أو في Cloudflare secrets أو السجلات بواسطة التطبيق، بل تُرسل عبر HTTPS مع كل طلب إلى Worker ثم إلى المزود الذي اختاره المستخدم. ينبغي عدم تفعيل Logging Bodies أو request logging لدى أي خدمة وسيطة.
- **افتراضيًا sessionStorage**؛ عند اختيار الاحتفاظ بالمفتاح يستخدم localStorage غير المشفر. هذا غير ملائم لأجهزة مشتركة أو مفاتيح ذات امتيازات عالية. استخدم مفاتيح مقيدة بحدود الإنفاق وراقب استخدامك.
- المحادثات محفوظة في localStorage على جهاز المستخدم فقط. الصور لا تُخزّن بعد إعادة تحميل الصفحة؛ تصدير المحادثات لا يصدّر المفاتيح ولا الصور.
- لا يمكن للموقع إجراء عمليات لا يدعمها النموذج أو مزوده؛ البحث المباشر بالويب، توليد الصور، تنفيذ الأكواد، التعامل مع PDF، والتحكم بالحسابات الخارجية **ليست مفعلة** في هذا الإصدار.
- كل مزود API له حدود استخدام وشروط وتكلفة مستقلة. إضافة مفاتيح متعددة لا تمنح رصيدًا مجانيًا بلا حدود ولا تتجاوز حصص مزوّد الخدمة.
- لا تستخدم مفتاح منصة الإنتاج السري في واجهة عامة من دون سياسة إدارة مفاتيح وتسجيل دخول وقيود إنفاق إضافية.
